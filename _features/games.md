# Games

Yes, it runs DOOM! ZenOS is capable of running several classic games natively through its application ports.

## Supported Games
- **DOOM**: Fully playable from the ZenOS terminal. Just run `doom` to launch it.
- **ClassiCube**: A lightweight Minecraft Classic clone that runs smoothly.
- **glxgears**: Standard OpenGL testing utility running on the TinyGL software rasterizer.
