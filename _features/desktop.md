# Graphical Desktop

ZenOS features a rich graphical environment with support for both its custom in-kernel desktop and industry-standard X11 window managers.

## In-Kernel Desktop
ZenOS ships with its own natively rendered desktop environment with a taskbar, framed windows, and a dark "Zen" styling.

## X11 & Window Managers
ZenOS fully supports a functional **X11** desktop. You can run:
- **ZWM (Zen Window Manager):** A custom window manager that ports the kernel desktop's dark styling into X11. It features keyboard controls, a taskbar, and a launcher menu.
- **TWM:** The classic Tab Window Manager is also supported.

### ZWM Shortcuts
- `Super+Enter`: Open a terminal (xterm)
- `Super+F`: Open Files
- `Super+Space`: Toggle launcher
- `Super+Tab`: Cycle windows
- `Super+F4`: Close focused window
- `Super+Q`: Quit ZWM session
