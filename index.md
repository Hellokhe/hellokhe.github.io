# ZenOS

{: .warning } 
This website is under active construction. ZenOS has not been released to the public yet!

**ZenOS** is a 64-bit bare-metal operating system with:

- Ring 3 userspace
- ELF execution
- Experimental X11 + TWM support
- Experimental coreutils
- W.I.P custom X11 apps

No Linux, No backbone OS! Just your zenOS kernel running everything. :D
