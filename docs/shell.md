# bash/sh in ZenOS

ZenOS provides basic shell support through `bash` and `sh`.

## sh

`sh` is the minimal POSIX-style shell.

```bash
sh script.sh
```

Used for simple scripting and system commands.

## bash

`bash` is the interactive and extended shell.

```bash
bash
bash script.sh
```

Used for interactive terminal use and more advanced scripting.
