iOS 7.x Setup & Installation Guides

📥 How to Add this Repo in Cydia

  1. Launch Cydia from your home screen.
  2. Tap the Sources tab at the bottom, then tap Edit in the top-right corner.
  3. Tap Add in the top-left corner.
  4. Enter: https://hellokhe.github.io/repo/ (or tap "Add to Cydia" above).
  5. Tap Add Source and wait for Cydia to reload packages.

⚡️ How to Install Unsigned Apps (.IPA) using AppSync Unified

  1. Install AppSync Unified from this repo inside Cydia.
  2. Reboot or respring your device once after installation.
  3. Method A (PC/Mac): Plug your device into your computer, open iFunBox or 3uTools, select Install App (.ipa) and choose your IPA file.
  4. Method B (On-Device Terminal): Install appinst from this repo, place your IPA on your device, and run:
    appinst /var/mobile/Downloads/MyGame.ipa

🔧 Offline / Manual .deb Installation via AutoInstall

If your device lacks Wi-Fi or Cydia isn't working yet:

  1. Download any .deb file directly from the links above.
  2. Connect your device to your computer via USB (using iFunBox or Cyberduck/SFTP).
  3. Place the downloaded .deb into:
    /var/root/Media/Cydia/AutoInstall/
    (Create the AutoInstall folder if it doesn't already exist)
  4. Reboot your iPhone/iPad twice. Cydia's background daemon will automatically install the package!
