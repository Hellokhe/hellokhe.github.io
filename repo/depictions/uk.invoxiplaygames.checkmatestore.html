Fixes App Store "Not Compatible" Errors: On legacy devices, Apple's App Store checks modern device capabilities (like Bluetooth LE or 64-bit requirement) before checking firmware compatibility. This tweak removes that capability roadblock.
Overview

Checkmate, Store! hooks into the App Store on iOS 7 to bypass device capability checks. If an app you purchased has an older version that worked on iOS 7, but the latest version requires newer hardware or iOS 15+, this tweak forces the App Store to prompt you to download the "Last Compatible Version" instead of blocking you outright.
