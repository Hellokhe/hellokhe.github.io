Overview

AppSync Unified is a tweak that patches installd on iOS, enabling the permanent installation of unsigned, fakesigned, ad-hoc, or expired IPA packages directly onto your jailbroken device.

Unlike sideloading on non-jailbroken devices, apps installed with AppSync Unified never expire, don't require resigning every 7 days, and have no arbitrary 3-app sideload limit.

Key Features for iOS 7
  • Install Any Compatible IPA: Archive or sideload classic iOS 7 games and utilities without certificate checks.
  • Works with Desktop Tools: Full compatibility with iFunBox, 3uTools, Apple Configurator, and iTunes.
  • Terminal Support: Fully integrates with the appinst CLI utility for installing IPAs straight from mobile terminal or SSH.
  • Substrate Hook: Automatically attaches to installd via MobileSubstrate on boot.
Post-Installation Instructions
  1. Install AppSync Unified from Cydia or via dpkg -i.
  2. Important: Respring or reboot your device once to initialize MobileSubstrate.
  3. You can now transfer and install IPA packages via iFunBox, Safari, or terminal.
