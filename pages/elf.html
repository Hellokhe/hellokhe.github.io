ELF Applications

ZenOS includes a first-cut ELF64 loader, allowing you to run compiled binaries inside the OS.

How it works

Place your .ELF files into:

usr/bin/elfassets/

Then build and run ZenOS:

make run

Running ELF programs

elf HELLO.ELF
elfu UHELLO.ELF
elfu shell
elfu -b UTICK.ELF demo

elf and elfu are used to launch binaries from the terminal.

Notes

  • This is an early implementation
  • Not all binaries will work yet
  • Designed for future userspace support

Why this matters

This is the foundation for a real userspace system. Eventually, ZenOS will be able to run full applications compiled outside the kernel.
