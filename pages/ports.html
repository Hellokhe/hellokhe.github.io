Ports System

ZenOS includes a ports system for building and staging real userspace software, including X11 applications.

Getting started

make ports-sysroot
make ports-env

This creates a sysroot at:

ports/build/x86_64-zenos/sysroot
---

Core components

  • musl libc (headers + runtime)
  • X11 protocol headers (xorgproto)
  • pixman (rendering)
  • X11 client libraries (libX11, libXext, libXi, etc.)
---

Building software

make ports-pixman
make ports-libx11
make ports-xeyes

ZenOS can now build real upstream X11 applications.

---

X11 Support

ZenOS includes an experimental X11 prototype environment.

x11-proto-debug -b
x11-proto-run xeyes

This allows running real X11 applications inside ZenOS.

---

Window Manager (TWM)

ZenOS can run classic X11 environments including twm (Tab Window Manager).

This means:

  • Multiple windows
  • Window movement and focus
  • Real X11 session behavior
---

Runtime sync

make ports-runtime-sync

This copies built binaries and libraries into the ZenOS filesystem:

  • /usr/bin
  • /usr/lib
  • /usr/share/X11
---
